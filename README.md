# aozbakir.github.io

Personal academic site for Ali Değer Ozbakir, built with [Academic Pages](https://github.com/academicpages/academicpages.github.io) (a Jekyll theme). Served automatically from the `main` branch via GitHub Pages.

## Local preview

```
bundle install
bundle exec jekyll serve
```

## Editing content

* `_config.yml` — site-wide settings (name, bio, links)
* `_pages/about.md` — homepage bio
* `_pages/cv.md` — CV page
* `_publications/` — one file per publication
* `_teaching/` — one file per course
